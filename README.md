#  Weather App

A simple and responsive Weather App built with HTML, CSS, and JavaScript.
It fetches real-time weather information for a city using the OpenWeather API.

##  Features

-  Search for weather by city name
-  Display temperature in Celsius
-  Display humidity
-  Show weather conditions and corresponding weather icons
-  Handle invalid city names and errors
-  Custom background and styling
-  Simple, user-friendly interface

##  Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- OpenWeather API

## How to Use

1. Enter a city name in the search field.
2. Click the **Submit** button.
3. View the current weather information for that city.
